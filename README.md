# GP AI Native Company — Public Methodology & Roadmap

이 저장소는 GP Company 내부 운영체계의 원문을 공개하는 공간이 아니라, 실제 운영 경험에서 일반화한 **공개 교육용 파생물**과 앞으로 축적될 **AI Native Company 전환 히스토리·로드맵**을 기록하는 공개 저장소다.

내부 Company Authority는 별도 private repository에서 관리하며, 이 저장소에는 검토·일반화·비식별화된 공개 가능한 방법론과 사례만 남긴다.

## 공개 원칙

- 내부 Company OS 원문을 그대로 복사하지 않는다.
- 실제 고객정보, 처방, 원가, 계약, 장비 접속정보, 운영 계정, 지원과제 민감 세부는 포함하지 않는다.
- 내부 Decision/Context의 세부 사실보다, 재사용 가능한 방법론과 구조를 공개한다.
- 공개 자료는 교육·콘텐츠·컨설팅 진입점으로 사용하되 내부 권위 원본이 아니다.
- 앞으로의 변화는 완성된 결과만이 아니라, 중요한 전환점·검증된 학습·방법론의 진화를 중심으로 기록한다.

## 핵심 방법론

1. **Context를 외부화한다** — AI의 기억보다 회사가 관리하는 Context와 Decision을 우선한다.
2. **사고와 실행을 분리한다** — 사람은 방향·창의·판단, AI는 구조화·반복·검증을 맡는다.
3. **작은 실행 루프를 만든다** — BOOT → THINK → DECIDE → EXECUTE → VERIFY → LEARN.
4. **학습을 재사용한다** — 실행 결과가 다음 실행자의 입력으로 돌아가야 한다.
5. **집중력을 보호한다** — 자동화의 성공은 대표가 기억·관리해야 할 항목이 줄어드는지로도 평가한다.

## 이 저장소가 앞으로 기록할 것

- GP Company가 AI Native Company로 전환하면서 생기는 중요한 방법론 변화
- 실제 실행에서 검증된 운영 패턴과 일반화 가능한 학습
- 교육·로드맵으로 공개할 수 있는 단계별 발전 과정
- 내부 Authority와 외부 공개 지식 사이의 안전한 경계

## 주의

이 자료는 GP Company 내부 운영 원본의 대체물이 아니다. 실제 내부 정책·상태·실행은 별도 private authority에서 관리한다.
