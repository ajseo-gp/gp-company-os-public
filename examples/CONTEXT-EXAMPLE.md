# Context Example — 고객문의 자동화

- 상태: REVIEW
- 목적: 고객문의 확인과 초안 작성 시간을 줄인다.
- 범위: 공개 예시이며 실제 회사 데이터가 아니다.

## Confirmed Facts

- 문의가 이메일, 웹폼, 전화 등 여러 채널로 들어온다.
- 사람이 모든 문의를 처음부터 읽고 분류하면 시간이 많이 든다.

## Working Hypotheses

- 문의를 한 곳에 모으면 누락이 줄어들 수 있다.
- AI가 고객문의와 비고객 메일을 분류하면 사람이 읽어야 할 양이 줄어들 수 있다.

## Constraints

- 고객정보를 공개 저장소에 남기지 않는다.
- 자동 회신은 별도 검증 전 활성화하지 않는다.

## Next Experiment

1. 과거 비식별 문의 샘플로 분류 정확도를 측정한다.
2. 사람의 기존 처리시간을 기준선으로 기록한다.
3. AI 분류 후 사람이 검토한 시간과 오탐을 비교한다.

## Decision Needed

정확도가 기준을 넘으면 초안 생성까지 확장할지 검토한다.
